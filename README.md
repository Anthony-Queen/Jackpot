A Slot Machine heavily inspired by Persona 1's JUDGEMENT 1999's slot: Press the Spacebar to stop the reels, then use the arrow keys to move each batch of small slots clockwise, when you're done press ENTER, and then press it again to restart the spinning.
To play the game just install it from itch.io: https://anthony-queen.itch.io/jackpot

You can see an image under the reels, that tells you how many coins you get by lining which symbols, like a normal slot machine, but better.
The small reels always move clockwise. Basically I use two cointainers, the first one moves 90 degrees clockwise, while the other one(the one With the sprites in it) moves COUNTERclowckwise 90 degrees, so the small reels can change positions easily
